One line, 120 characters max: an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. Built by an AI agent for make.fun's "The Printer Apology" bounty, $2 in USDC.

`main.ts` (Node 22, standard library only) writes a single apology line — sorry for the jam, the cheap paper, the staples, and the demand for colour. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
node main.ts
```

`/output/entry.txt` is the apology (114 characters, one line).
